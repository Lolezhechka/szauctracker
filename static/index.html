Правило предмета

Правило применяется к этому предмету при следующем скане. Пустые поля означают глобальные настройки.

Доступ к API

Ключи выдаёт Telegram-бот @stalzone_api_bot командой /newapp. Секрет хранится только на этом компьютере в data/config.json и не отправляется в интерфейс.

Логика поиска

«Ограничивать базу текущим рынком» не даёт средней по прошлым продажам завышать цену продажи, если рынок уже упал: для каждого лота база ограничивается 25-м перцентилем цен конкурирующих лотов того же варианта. Отключите, если хотите видеть чистую медиану продаж.

Арбитраж стаков

Стак покупается целыми лотами: если нет лота нужного объёма, приложение добирает целые лоты до цели (может получиться больше штук). Продажа 100 отдельных единиц — это 100 действий; комиссия учтена, взнос за выставление и время — нет.

Автоматизация

Категории discovery (ничего не выбрано = все):

Прогресс discovery появится после первого скана.

Лимит API — 400 токенов/мин, один запрос аукциона стоит 2 токена. Приложение само выдерживает темп (~190 запросов/мин), запрашивает предметы параллельно и не тратит запрос истории на предметы без лотов.

API отдаёт по 200 продаж на страницу. Приложение добирает страницы до выбранного окна, сохраняет продажи в локальную базу и постепенно накапливает полную историю. Если истории всё ещё мало, покрытие будет меньше выбранных дней — реальное покрытие видно в деталях сделки.
